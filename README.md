# DISC//HUNT

An augmented-reality reflex game where a pistol-shaped hand aims the crosshair and a quick backward recoil fires at flying discs.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173` in a browser, enable the camera, and hold the pistol pose until the posture indicator turns green.

## Controls

- Extend the index finger to aim.
- Curl the middle, ring, and pinky fingers.
- Jerk the hand backward to shoot.
- Mouse and touch remain available as fallback controls.
